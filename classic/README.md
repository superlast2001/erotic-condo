# Erotic Condo — 18+ only

**Adults only (18+).** A browser-based condo management + touch game. Contains adult themes and sexually explicit **text** (adjustable: Teasing / Steamy / Explicit). Artwork is non-explicit.

**All characters are fictional adults (21+).** No real people. No minors.

Play: https://superlast2001.github.io/erotic-condo/

## Features
- Manage a condo: build/upgrade lounge, gym, bedroom, kitchen, library, sauna and rooftop; add floors; days pass and rent comes in; residents have moods.
- Residents: Wolf plus four new original adults — Bash, Dante, Kai, Brock. Move them in, give gifts/food, go on dates.
- Touch scenes: tap / drag / hold on body-zone hotspots; Arousal & Trust meters; four reaction stages; text-only finale that fades to black; affection levels unlock rooms, dates and rewards.
- Fully touch-playable (no hover UI, no pinch-zoom/scroll fighting). **Hide console** button gives a full-screen view.
- Settings: text intensity, reduced motion, hotspot outlines, instant text, auto-day, reset save. Saves to localStorage.

Plain HTML/JS/CSS — no build step. Open `index.html` or host statically.
